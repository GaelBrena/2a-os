# Nuestros 2 años

Álbum de Gael Daniel y Yeltzin Riquer. Cada mes tiene 8 fotos (dos por semana, una de cada quien) y en medio un mensaje de cada uno. Las semanas se van abriendo solas con el tiempo, empezando el 22 de noviembre de 2026.

## Publicarlo en GitHub Pages

1. Crea un repositorio nuevo en GitHub (por ejemplo `nuestros-2-anos`) y déjalo **público** (GitHub Pages gratis lo necesita).
2. Sube los archivos de esta carpeta tal cual: `index.html`, `mensajes.js` y la carpeta `fotos`.
3. En el repositorio ve a **Settings → Pages**. En *Branch* elige `main` y la carpeta `/ (root)`, y guarda.
4. En uno o dos minutos tu página estará en `https://TU-USUARIO.github.io/nuestros-2-anos/`.

## Para que Yeltzin también pueda subir fotos

En **Settings → Collaborators** invita su cuenta de GitHub. Cuando acepte, podrá subir y borrar fotos igual que tú.

## Agregar una foto

1. Entra a la carpeta `fotos` del repositorio.
2. **Add file → Upload files**, arrastra la foto y toca **Commit changes**.
3. El nombre tiene que ser exacto: `mes1-sem1-gael.jpg`, `mes1-sem1-yeltzin.jpg`, `mes1-sem2-gael.jpg`… (ver `fotos/LEEME.txt`).

Renombra la foto en tu celular o compu antes de subirla.

## Quitar o cambiar una foto

Abre la foto dentro de `fotos`, toca los tres puntos (**…**) → **Delete file** → **Commit changes**. Luego sube la nueva con el mismo nombre.

## Escribir los mensajes del mes y las notas de las fotos

Abre `mensajes.js`, toca el lápiz (**Edit**), escribe entre las comillas y guarda con **Commit changes**.

## Cosas a saber

- Después de subir o borrar algo, la página tarda uno o dos minutos en actualizarse.
- Como el repositorio es público, quien encuentre el repositorio puede ver las fotos aunque la página las tenga bloqueadas.
